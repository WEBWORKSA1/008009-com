## Stack
Pure static HTML/CSS/vanilla JS generated by a small Python script. There are no runtime dependencies and no server, so it runs on the GitHub Pages free plan.

```
build/        generator (layout, data, guides, build.py, images.py)
assets/css    design system (light/dark)
assets/js     config.js (monetization switchboard) · numerology.js (engine) · main.js (site) · tools.js (calculators)
.github/      CI: builds the site on every push to main and publishes it to the gh-pages branch
```

The HTML pages are generated in CI, so you only edit sources. To build locally:
```bash
pip install pillow
python3 build/images.py
python3 build/build.py                                  # GitHub Pages URL
python3 build/build.py --base https://008009.com/       # custom domain (CI does this automatically if a CNAME file exists)
```

## Monetize (edit `assets/js/config.js`)
| Key | What |
|---|---|
| `adsenseClient` | `ca-pub-…` switches house ads to AdSense (also update `ads.txt`) |
| `ga4Id` | Google Analytics 4 |
| `youtubeChannelUrl` | shows the Subscribe button |
| `payments.*` | Stripe / PayPal / Ko-fi / BMC / GitHub Sponsors links (the pledge form is used until these are set) |
| `social.*` | footer social links |

## Forms
All forms (Exchange, consultations, contests, careers, advertising, donations, newsletter, contact) submit through FormSubmit's AJAX API to a private inbox. The address is stored encoded and is never shown on the site. **The first submission triggers a one-time FormSubmit activation email; click Activate.**
